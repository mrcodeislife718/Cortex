# Cortex Architecture Contracts

Cortex architecture is governed by executable contracts rather than aspirational prose.

- `superiority-contract.json` defines competitor strengths/weaknesses, Cortex innovations, measurement methods, benchmarks, fallbacks and 1x/10x/100x validation expectations.
- `full-product-contract.json` defines the complete product baseline and superiority layers: VS Code-class IDE completeness, Cursor-class AI/agents, Replit-class execution/deployment, JetBrains-class semantics, Zed-class responsiveness, plus Cortex-specific verification, System Graph, security, recovery, model independence, low-resource operation, governance and production awareness.
- `workbench-interaction-contract.md` defines the user-boundary evidence required before visible desktop workflows can be called working.

These contracts define requirements. They do not themselves promote features to PASS. Evidence must come from executable qualification or external systems appropriate to the claim.
