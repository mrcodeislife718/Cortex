# Cortex — Portfolio Proof Contract

**Track:** Commercial developer / IDE product

Cortex is complete only when developers can use it to perform real coding workflows reliably, safely, and measurably better than the chosen baseline.

Required proof: edit/build/test/debug/project workflows; state/recovery/plugin/integration tests; failure tests for malformed projects, tool crashes, partial edits, dependency loss, and workspace corruption; benchmarks for startup, indexing, edit-to-feedback latency, memory, and task completion; extension/workspace security; install/update/rollback; real developer usage, retention, and paid adoption where commercialized.

**Next proof target:** run a representative multi-file project through edit, build, test, debug, crash/restart, and recovery flows while measuring latency, memory, correctness, and lost-work prevention.
