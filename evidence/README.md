# Cortex Evidence

Evidence files describe what has and has not been proven on a qualifying commit. They are not marketing claims.

`PASS` requires executable or externally inspectable evidence for the named property. `PARTIAL` means meaningful implementation exists but one or more required integrations, platforms, scale targets, external systems or user-boundary proofs remain. `UNVERIFIED` means implementation may exist but sufficient qualifying evidence has not been produced.

A successful compile, package artifact, rendered UI or process-start smoke test cannot promote an interactive workflow to `PASS`. The packaged workflow itself must be exercised or an equivalent independently inspectable behavior must be proven.
